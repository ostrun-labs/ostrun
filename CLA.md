Merci de vouloir contribuer à Ostrun ! En soumettant une contribution (via pull request ou tout autre moyen), vous ("le Contributeur") acceptez ce qui suit :

## 1. Définitions

- **"Contribution"** désigne tout code source, documentation, configuration, ou autre matériel original que vous soumettez au projet Ostrun.

Vous accordez au Projet une licence **perpétuelle, mondiale, non-exclusive, gratuite, irrévocable** sur votre Contribution, incluant le droit de :

- l'utiliser, la reproduire, la modifier, la distribuer et la sous-licencier ;

Cette licence n'est **pas exclusive** : vous restez libre d'utiliser, republier ou relicencier votre propre Contribution ailleurs, dans un autre projet, comme bon vous semble. Vous conservez la paternité (attribution) de votre travail.

## 4. Vos garanties

Vous déclarez que :

## 5. Absence de garantie de votre part

Votre Contribution est fournie **"telle quelle"**, sans garantie d'aucune sorte de votre part (fonctionnement, adéquation à un usage particulier, absence de bug, etc.).

## 6. Acceptation

L'acceptation de ce CLA se fait électroniquement, généralement via un commentaire automatique du bot CLA Assistant sur votre première pull request. Cette acceptation vaut pour toutes vos contributions futures au Projet, sauf révocation explicite de votre part (auquel cas les contributions déjà acceptées restent couvertes par ce CLA pour la période où il était en vigueur).
